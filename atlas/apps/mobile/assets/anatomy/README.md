# Modelo anatômico

Base: dois SVGs em polígonos fornecidos pelo usuário em 11/09/2026. Somente geometria foi importada; HTML, estilos e cores foram descartados. Frente e costas foram ajustadas ao viewBox do Atlas, preservando todos os polígonos de base.

Os 26 identificadores existentes foram preservados. Como a referência não possui rótulos, subdivisões de peitoral, deltoide, abdome, trapézio e glúteos são esquemáticas. Músculos profundos não são representações de sua localização clínica. O modelo serve à exploração dos dados de treino; exige revisão anatômica antes de uso educativo clínico.

Cores e seleção vêm dos tokens e dos dados validados do aplicativo. Arquivos mestre sem estilos fixos.
